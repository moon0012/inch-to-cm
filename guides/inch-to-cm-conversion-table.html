How to Use This Conversion Table

This page provides a complete inch-to-centimeter reference chart covering whole inches from 1 to 100, as well as common fractional inch values. To find your conversion, simply locate the inch value in the left column and read the corresponding centimeter value on the right.

Every value in this table is calculated using the exact conversion factor: 1 inch = 2.54 centimeters. The results are rounded to two decimal places, which is sufficient for nearly all practical applications.

Tip: Press Ctrl+F (Cmd+F on Mac) to quickly search for a specific value on this page. You can also print this page -- the tables are formatted for clean printing with navigation elements hidden automatically.

When Tables Are Better Than Calculators

You might wonder why anyone would use a reference table when a calculator is always within reach. There are several situations where tables are genuinely more practical:

  • Workshop environments. In a woodworking shop or sewing room, your hands are often occupied. A printed table pinned to the wall lets you glance at a value without touching a device. No unlocking a phone, no typing, no worrying about sawdust on your screen.
  • Repeated lookups. If you are working on a project that requires dozens of conversions -- cutting fabric to metric patterns from imperial yardage, for example -- scanning a table is faster than entering each value individually.
  • Verification. When a conversion matters (ordering materials, specifying dimensions for manufacturing), a table provides an independent check against your calculated result. It takes two seconds to confirm that 36 inches is indeed 91.44 cm.
  • Offline or low-tech settings. In classrooms, on construction sites with poor signal, or in countries where internet access is unreliable, a printed table is always available.
  • Learning and memorization. Students and professionals who work with conversions regularly benefit from seeing the values laid out in sequence. Patterns become apparent -- like the fact that every 10 inches adds 25.4 cm -- making mental estimation easier.

How to Read the Table Correctly

A few pointers for getting the most out of this reference:

  1. For whole inches, find the row directly. If you need 47 inches in centimeters, locate 47 in the left column: 119.38 cm.
  2. For fractional inches, use the fractional table at the top of this page first, then add the whole-inch value. For example, 23 3/4 inches: find 23 inches (58.42 cm) and add 3/4 inch (1.91 cm) = 60.33 cm.
  3. For values above 100 inches, combine entries. 150 inches = 100 inches (254.00 cm) + 50 inches (127.00 cm) = 381.00 cm.
  4. To go from cm to inches, scan the centimeter column for the value closest to yours, then read the corresponding inch value. For exact reverse conversions, use our converter tool.
